******
Domain
******

This section describes the shape of the DALME **domain**: the concepts,
contexts and language the system is built from, stated in terms that a scholar
and a developer can share.

We practise `domain-driven design
<https://en.wikipedia.org/wiki/Domain-driven_design>`_. We model the domain in
the abstract, in natural language, before and alongside any implementation of it
in code. The model of record lives in the repository's ``CONTEXT.md`` files;
these pages are their reader-facing companion.
